# NoAgent Real Estate Prototype

This repository contains a simple prototype for a real estate platform where buyers and sellers interact without agents. It uses basic HTML, CSS and JavaScript so it can run as a static site. The layout is inspired by popular Australian property portals to provide a familiar experience.

## Pages

- **index.html** – homepage with search bar, featured listings and links to other sections.
- **buyer.html** – buyer dashboard with smart filters, recommended properties and AI agent panels.
- **property.html** – property detail page with tabs for additional data and a voice query button.
- **seller.html** – form for sellers to upload a property and generate a description and price suggestion.
- **about.html** – simple page with personal info.

Mock data and placeholder interactions demonstrate how AI functionality can be integrated in the future.
